Learn SQL by doing.

Explore SQL commands by querying and manipulating preloaded database tables. Write commands, execute them and see the results instantly.

This is a learning environment. All records are fictional sample data, not real personal or business information.

Getting started

Select a table to inspect its records, then head to the SQL command interface to experiment with queries. You can modify the sample data as you learn.

Quick SQL commands

SELECT — Read data

Retrieve records from a table.

SELECT * FROM inventory;

WHERE — Filter records

Find records that meet a condition.

SELECT * FROM members WHERE id = 1;

INSERT — Add records

Add a new row to an existing table.

INSERT INTO inventory
         (name, total, available, rented, status)
         VALUES ('Laptop', 10, 10, 0, 'Good');

UPDATE — Modify records

Change values in existing records.

UPDATE members
         SET phone = '0700000000'
         WHERE id = 1;

DELETE — Remove records

Delete records that match a condition.

DELETE FROM members WHERE id = 1;

JOIN — Combine tables

Retrieve related information from multiple tables.

SELECT members.name, rentals.item
         FROM members
         JOIN rentals
         ON members.name = rentals.name;

Know your tables

inventory — Sample items, quantities, availability and status.

members — Sample member names, phone numbers and identification records.

rentals — Sample rental transactions, items, quantities and payments.

Things to remember

  • SQL keywords are generally written in uppercase for readability.
  • Use single quotes around text and date values.
  • Separate commands with semicolons.
  • Use WHERE with UPDATE and DELETE to target specific records.
  • Use SELECT * to retrieve all columns from a table.
  • Changes are saved to the local JSON database.
  • This is a simplified SQL implementation, so not every standard SQL feature is supported.
